1. Executive Summary & Vision

The DCF Valuation & Financial Analytics Platform is an institutional-grade financial application designed for equity research analysts, quantitative investors, and corporate finance practitioners. It unifies classical Discounted Cash Flow valuation, market-implied growth solving (Reverse DCF), and DuPont operational decomposition into an interactive visual dashboard.

Built on clean architectural principles, the system decouples a network-isolated financial math engine from an external market ingestion layer and a reactive Streamlit/Plotly frontend. It features real-time multi-currency support, in-memory TTL caching, resilient error boundaries, and a 14-test deterministic unit suite.

4. Reverse DCF: Solving Market-Implied Growth Rates

Reverse DCF inverts the valuation equation: given the observable market stock price $P_{\text{market}}$, it solves for the 5-year annual growth rate ($g_1^*$) implied by the market.

Target Enterprise Value = P_market × Shares + Total Debt - Cash
f(g_1) = IntrinsicValue(g_1) - P_market = 0
  • Primary Solver (scipy.optimize.brentq): Brent's hybrid root-finding algorithm converges to $10^{-6}$ tolerance in < 10 iterations.
  • Binary Search Fallback: Custom bisection solver with dynamic bracket expansion guarantees execution across all environments.
  • Verification: Evaluates forward DCF on $g_1^*$ to prove convergence with |validation_price - target_price| < 1e-4.

5. 3-Stage DuPont ROE Decomposition & Delta Attribution

Deconstructs Return on Equity (ROE) into operational profitability, asset turnover, and financial leverage:

ROE = (Net Income / Revenue) × (Revenue / Total Assets) × (Total Assets / Equity)
ROE = Net Profit Margin × Asset Turnover × Equity Multiplier

5.1. Exact-Path Sequential Delta Attribution

When comparing two periods ($T_0 \to T_1$), sequential path substitution attributes changes with 0% residual:

Δ ROE = Margin Effect + Turnover Effect + Leverage Effect
• Margin Effect = (Margin_1 - Margin_0) × Turnover_0 × Leverage_0
• Turnover Effect = Margin_1 × (Turnover_1 - Turnover_0) × Leverage_0
• Leverage Effect = Margin_1 × Turnover_1 × (Leverage_1 - Leverage_0)
Benchmark Case Study:
Period $T_0$: Margin = 10.0%, Turnover = 0.80x, Leverage = 2.50x → ROE = 20.0%
Period $T_1$: Margin = 12.0%, Turnover = 0.83x, Leverage = 2.40x → ROE = 24.0% (Δ ROE = +4.0%)
• Margin Expansion: +4.00% (100% of gain) • Asset Turnover: +1.00% (+25% of gain) • Deleveraging: -1.00% (-25% drag).

6. Live Ingestion, Multi-Currency & Error Boundaries

  • Multi-Currency Auto-Detection: Ingested tickers automatically format the entire dashboard in reporting currency (e.g. ₹ for TATASTEEL.NS, $ for AAPL, € for MC.PA, £ for AZN.L, ¥ for 7203.T). Includes a manual currency override selector.
  • In-Memory TTL Caching: Thread-safe cache with a 300-second TTL prevents repeated API calls and eliminates rate-limiting.
  • Graceful Error Boundaries: Empty-input guards, custom TickerNotFoundError handlers with international exchange suffix guidance, and balance sheet disclosure disclosures ensure the app never crashes.
